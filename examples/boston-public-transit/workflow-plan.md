# Workflow Plan

1. Captain: confirm project brief and map scope
2. Scout: source and inspect official MBTA GTFS feed
3. Sentinel: validate route types, shape joins, geometry, coverage, and CRS
4. Analyst: convert GTFS shapes to categorized EPSG:4326 GeoJSON
5. Cartographer: assign categories, line weights, legend, and popup fields
6. Web Builder: create direct-open Leaflet viewer with route-type toggles
7. Reviewer: document limitations and final release decision
